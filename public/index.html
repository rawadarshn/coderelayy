Terms & Conditions

1. Shared editing. Anyone with the workspace link can view and edit the current code until the owner turns on the editing lock. Share links only with people you trust.

2. Owner editing lock. The owner can lock editing. Other visitors can still read and copy code, but the server rejects their edit attempts. This is an editing permission lock, not encryption of the code contents.

3. No history or permanent storage. CodeRelay does not keep edit history or write workspace code to a database or file. The active code is held in server memory while the room exists. Restarting the server clears all rooms.

4. No secrets. Do not paste passwords, API keys, access tokens, private keys, personal information, or confidential code into a shared workspace.

5. Availability. Rooms can disappear if the server restarts, runs out of memory, or the host sleeps. A QR code is only a link; remote collaboration requires a deployed server accessible to your team.

6. Responsible use. Use this service only for lawful collaboration. This prototype is provided as-is and these terms are a draft, not legal advice.
